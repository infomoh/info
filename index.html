نفس الفكرة بالكود

كلاس صغير ونداء دالة. في C++ نحن نقرر عمر الكائن، وفي C# الـ runtime يتكفل بالتنظيف.

C++
#include <iostream>
#include <memory>
#include <string>

class Player {
  std::string name;
public:
  Player(std::string n) : name(n) {}
  void greet() {
    std::cout << "Salam " << name << "\n";
  }
};

int main() {
  // smart pointer يحذف الكائن وحده
  auto p = std::make_unique<Player>("Ali");
  p->greet();
}
C#
class Player(string name)
{
  public void Greet() =>
    Console.WriteLine($"Salam {name}");
}

// GC يمسح الكائن لما ما يبقاش مستعمل
var p = new Player("Ali");
p.Greet();

C# أقصر لأن الـ runtime والمكتبة يعملو بدالك الكثير. C++ أطول لكن تشوف بالضبط شنو يصير في الذاكرة.
